# Internationalization

## Languages

| Code | Files | Scope |
|------|-------|-------|
| `en` | `messages.ts` (default export) | Full UI |
| `ru` | `messages.ts` (`ru:` block) | Full UI |
| `el` | `messages.el.ts` | Full UI (typed via cast) |

**Not localized:** most orthocal API raw strings — partial override via `orthocalContent.ts`.

## Usage

```typescript
const { t } = useAppTranslation();
t('settings.notifications');
t('settings.notificationsOnCount', { count: 3 });
t('settings.version', { version: '0.1.0' });
```

## Key namespaces

| Prefix | Purpose |
|--------|---------|
| `tabs.*` | Tab labels, browser titles, calendar header |
| `settings.*` | Settings screen |
| `calendar.*` | Calendar screen (`calendar.title` = “Liturgical calendar”) |
| `today.*` | Today screen, serving role labels |
| `notifications.*` | Push alert copy + Android channels |
| `orthocalFeasts.*`, `appearance.*` | Localized feast/fast names |
| `a11y.*` | Accessibility labels |

## Settings strings (recent decisions)

| Key | EN value | Notes |
|-----|----------|-------|
| `settings.sectionNotifications` | Notifications | Section/alert title |
| `settings.backgroundColour` | Background Gradient | Key name is legacy |
| `settings.notificationsRowHint` | Phone app only (iOS & Android) — not on web. | |
| `settings.notificationsMobileOnly` | Long modal subtitle | |
| `settings.notificationsWebOnly` | Web-specific footer | |

Row hints pattern: `settings.*RowHint` (short, under label in list).

Longer help text: `settings.*Hint` (used in modals or older UI).

## Content localization

**File:** `src/i18n/orthocalContent.ts`

- `FEAST_KEY_BY_ENGLISH` — exact orthocal title → i18n key
- `HONORIFIC_RULES` — RU (and EL) saint title abbreviations
- `localizeServiceNotes()` — wired into `dayDashboard.ts`

When adding feasts: add EN key + RU in messages + EL in messages.el.ts.

## Greek type parity

`messages.el.ts` exported as `el as unknown as MessageTree` for TS parity with EN — add missing EL keys when typecheck fails.

## Browser / document titles

Each tab screen sets `<Head><title>` via `expo-router/head`:
- `tabs.browserTitleCalendar`
- `tabs.browserTitleSettings`

Today uses brand header in tab bar on desktop, not a duplicate text title.
